# 가드레일 — 산출물에 넣으면 안 되는 것

서버가 자동 생성할 때는 중앙에서 검사가 강제됐다. 개인 Claude로 옮기면 그 검문소가 사라지므로 같은 규칙을 기계와 사람이 함께 지킨다.
문장 규칙(근거 없는 문장 금지 · `⚠️ 확인필요` 표기 · 되돌리기 금지)은 `writing.md` §1에 있다.

## 1. 공개 금지 정보 — `render_html.py`가 기계로 막는다
아래가 본문에 있으면 **렌더를 거부한다.** 우회하지 말고 본문을 고친다. Figma 파일에도 넣지 않는다(링크는 쉽게 밖으로 나간다).

| 패턴 | 이유 |
|---|---|
| 사설망(tailnet) IP `100.x.x.x` | 서버 위치 노출 |
| 내부 포트 `:8787` | 서비스 노출 |
| 모델명 `gemini` `gpt-4` `claude-<이름>-<숫자>` | 사용 도구 노출 |
| 슬랙 채널·유저 ID `C0…` | 내부 채널 노출 |
| 서버 경로 `/opt/vax` `/var/lib/vax` `/var/www` | 내부 구조 노출 |
| 토큰 `xoxb-` `xoxp-` `xapp-` | 자격증명 |

## 2. 사람이 봐야 하는 것 — 기계가 못 잡는다
- **임직원 실명**: 동명이인·일반명사라 자동으로 못 잡는다. 제안서에 실명이 필요하면 발주처 제출용으로 허용된 범위인지 확인한다. 연령은 서식이 요구할 때만.
- **대외비 수치**: 원가·마진·미확정 실적·내부 평가 점수. 재료 팩 §6(정량 지표)은 판단용이지 본문에 옮기는 것이 아니다.
- **재무**: 회사소개서(대외용)는 재무 제외가 원칙(`vax-exit-kit` 규칙과 같다).
