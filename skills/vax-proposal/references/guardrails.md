# 가드레일 — 산출물에 넣으면 안 되는 것과, 쓰지 말아야 할 문장

서버가 자동 생성할 때는 중앙에서 검사가 강제됐다. 개인 Claude로 옮기면 그 검문소가 사라지므로
**같은 규칙을 여기서 기계와 사람이 함께 지킨다.**

## 1. 공개 금지 정보 — `render_html.py` 가 기계로 막는다
아래가 본문에 있으면 **렌더를 거부한다.** 우회하지 말고 본문을 고친다.

| 패턴 | 이유 |
|---|---|
| 사설망(tailnet) IP `100.x.x.x` | 서버 위치 노출 |
| 내부 포트 `:8787` | 서비스 노출 |
| 모델명 `gemini` `gpt-4` `claude-<이름>-<숫자>` | 사용 도구 노출 |
| 슬랙 채널·유저 ID `C0…` | 내부 채널 노출 |
| 서버 경로 `/opt/vax` `/var/lib/vax` `/var/www` | 내부 구조 노출 |
| 토큰 `xoxb-` `xoxp-` `xapp-` | 자격증명 |

## 2. 사람이 봐야 하는 것 — 기계가 못 잡는다
- **임직원 실명**: 동명이인·일반명사라 자동으로 못 잡는다. 제안서에 실명이 필요하면 발주처 제출용으로 허용된 범위인지 확인한다.
- **대외비 수치**: 원가·마진·미확정 실적·내부 평가 점수. 재료 팩 6(정량 지표)은 **판단용**이지 제안서 본문에 그대로 옮기는 것이 아니다.
- **재무**: 회사소개서(대외용)는 재무 제외가 원칙(`vax-exit-kit` 규칙과 같다).

## 3. 쓰지 말아야 할 문장
- **근거 없는 주장**: 재료 팩에 없는 실적·인증·수치. → `⚠️ 확인필요 — <무엇이 필요한지>`로 남긴다.
- **새로 만든 숫자·고유명사**: 재료 팩과 공고 원문에 있는 것만 쓴다.
- **"다 하겠다"**: 예산 밖 기술을 나란히 적는 것. 방향 단계에서 「안 할 것」을 먼저 정한다.
- **조용한 빈칸 메우기**: 모르는 것을 그럴듯한 문장으로 덮지 않는다. 누락은 눈에 보이게 표시한다.

## 4. ⚠️ 확인필요 표기법
```
⚠️ 확인필요 — 2024년 ○○사업 실적 금액(재료 팩 5에 없음, 회사 팩트 DB 확인)
```
초안 끝에 「확인필요 목록」 절을 두고 전부 모아 둔다. 담당자가 이 목록만 보고 채울 수 있게.
