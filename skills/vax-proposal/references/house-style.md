# 회사 디자인·문체 — HTML 디자인을 뽑을 때 지키는 것

## 디자인 정본은 한 곳
값은 `scripts/ui_tokens.py`(서버 `ops/ui_tokens.py`의 사본)에 있고 `render_html.py`가 자동으로
`<style>` 맨 앞에 끼운다. **HTML 안에 색·모서리·글꼴을 새로 적지 않는다.** 고칠 일이 있으면
서버 정본을 고치고 `server/sync_tokens.sh`로 옮긴다(반대로 하지 않는다).

### 알아 두면 좋은 뜻
- **무채색 원칙**: 표면 단계(캔버스 → 카드 → 보조면)와 잉크 단계(잉크 → 연잉크 → 회색)뿐이다.
- **자리마다 색이 다르다**: `brand` 남색 = 회사(워드마크·링크·표의 주인공 열) · `action` 보라 = 누르는 것(주 버튼 하나) · `fill` 검정 = 지금 있는 곳(선택된 탭).
- **뜻이 정해진 색 셋**: `ember` 빨강 = 오류에만 · `good` 초록 = 잘됨 · `warn` 주황 = 주의. 장식으로 쓰지 않는다. 배지는 옅은 바탕 + 같은 계열 진한 글자 + 1px 선.
- **모서리는 네 계열뿐**: 누르는 것 999(알약) · 카드 16 · 카드 안 판 10 · 배지·입력칸 6. 섞지 않는다.
- **간격은 4px 배수**: 카드 안쪽 24 · 요소 사이 16 · 12 · 8.
- **글자 단계 넷**: 화면 제목 26/600 · 카드 제목 16/600 · 그룹 제목 13/600 · 표 머리 12/500. 크기·굵기·색을 함께 달리한다.
- **글꼴 차례**: Geist(영문·숫자) → Pretendard(한글). 순서를 바꾸지 않는다(숫자 모양이 두 화면에서 달라진다).
- **다크모드**: 색을 새로 만들지 않고 표면 단계를 뒤집는다. ERP와 같은 `localStorage` 키 `vaxtheme`을 읽는다.
- 모든 글자색은 **WCAG AA 4.5 대비**를 통과한 값이다(`python3 scripts/ui_tokens.py --selftest`).

## 문체 — 「쉬운판」
사내 매뉴얼과 공개 페이지가 쓰는 문체다. 제안서 초안도 이걸 따른다.

- **짧게, 결론 먼저.** 한 문장에 한 가지. 명사 나열 대신 동사로 푼다.
- **본문 강조는 반굵게(600)**, 700 아님. 한 문장에 굵은 데가 여럿이면 화면이 통째로 굵어 보이고 정작 중요한 곳이 묻힌다.
- **번역투 금지**: "~을 통해", "~에 대한", "~에 있어", 이중 피동, "가지고 있다"를 쓰지 않는다. `fluent-korean` output-style이 켜져 있으면 대부분 잡힌다.
- **공문투 금지**: "진행하였습니다 / 반영이 필요합니다" → "했습니다 / 고쳐야 합니다".
- **어려운 개념은 풀어 쓴다**: 이름만 대지 않고 무슨 일이 벌어지는지로. 이름을 남겨야 하면 풀어 쓴 뒤 괄호.
- **결정에는 날짜와 결정자**를 남긴다(예: "한준 2026-08-21"). 왜 그렇게 정했는지가 규칙의 근거다.
- **표·불릿을 도배하지 않는다.** 목록이 셋을 넘으면 문장으로 바꿀 수 있는지 본다.
- 마무리에 `humanize-korean`으로 AI 티(기계적 병렬·관용구 남발·리듬 균일)를 걷어낸다. 내용은 한 글자도 바꾸지 않는다.

## HTML 골격 (render_html.py 가 만든다)
한 장짜리 문서. 상단 문서 머리(kick · 제목 · 메타) → 본문(목차 자동) → 하단 각주. `?embed=1`이면 머리띠를 감춘다(ERP 틀 안에 띄울 때).
지원 문법은 우리가 실제로 쓰는 것만: 제목 · 표 · 목록 · 인용 · 굵게 · 코드 · 구분선.
