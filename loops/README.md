# loops/ — 대표가 만든 루프·반복 절차

「같은 일을 정해진 순서로 되풀이하는」 절차들을 둔다. 형태는 셋 중 하나다.

1. **슬래시 커맨드형** (`*.md`): `~/.claude/commands/`에 복사하면 `/이름`으로 부른다. 한 번에 한 사이클.
2. **/loop 프롬프트형** (`*.loop.md`): Claude Code `/loop` 에 넘겨 주기적으로 도는 프롬프트. 첫 줄에 주기(`5m` 등)를 적는다.
3. **Workflow 스크립트형** (`*.workflow.js`): 여러 에이전트를 fan-out 하는 오케스트레이션. 토큰을 많이 쓰니 명시적으로 부를 때만.

## 파일 규약
- 파일 맨 위에 **목적 한 줄 · 입력 · 출력 · 끝나는 조건**을 적는다. 끝나는 조건이 없는 루프는 넣지 않는다.
- 서버 자동화(systemd 타이머)와 겹치는 일은 여기 두지 않는다 — 서버 것은 서버에서 돈다.
- 회사 팩트·서버 주소·내부 경로를 본문에 박지 않는다.

## 이 스킬셋과 어울리는 루프 예
- `proposal-review.loop.md` — 초안의 ⚠️ 확인필요가 0이 될 때까지 담당자에게 빈칸을 묻고 채운다.
- `figma-sync.md` — Figma에서 고친 문장을 노션 초안에도 반영해 사본을 맞춘다.

비어 있는 상태로 시작한다. 대표가 만든 파일을 그대로 넣으면 된다.
