# _BUILD_STATE.md — Figma 제작 재개 파일 (사업별 1개 · P6 제작 전용)

> **Figma 토큰은 30분마다 끊긴다. 끊기면 이 파일부터 읽는다.**
> 한 장에 한 호출로 만들고, 장 하나가 끝날 때마다 아래 표를 갱신한다.
> `_STATE.md`가 사업 전체의 상태 기계라면, 이 파일은 그중 P6 제작 한 단계의 손 기록이다.
> 새 사업의 덱을 시작할 때 `bids/{사업명}/_BUILD_STATE.md`로 복사해 쓴다.

## 대상 파일
```yaml
Figma파일키:    -              # figma.com/slides/<이것> · use_figma 호출마다 넣는다
파일이름:       -
발주처CI색:     -              # 예: #0068B0 (ci/ 폴더 로고에서 딴 hex · figma-howto.md)
총장수:         -
만든장수:       0
슬라이드계획:   07_슬라이드계획_v?.md   # 이 표의 근거
마지막갱신:     -
```

## 장별 노드 ID
> Figma 스크립트에서 `snapshotIds()`(figma_slides_helpers.js)를 돌리면 이 표가 문자열로 나온다. 그대로 붙인다.
> 「상태」는 손으로: `빈칸` → `틀만`(houseChrome·applyLayout) → `증거`(사진·표·도식까지) → `검증`(validate·evidenceCheck 통과).
