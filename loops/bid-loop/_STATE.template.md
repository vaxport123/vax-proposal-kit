# _STATE.md — 상태 기계 (사업별 1개)

> 이 파일이 진실의 원천이다. 대화 기억보다 이 파일을 우선한다.
> `/bid-loop` 는 이 파일을 읽고 시작하고, 이 파일을 갱신하고 끝난다.
> 새 사업 시작 시 이 템플릿을 `bids/{사업명}/_STATE.md` 로 복사해 쓴다.
