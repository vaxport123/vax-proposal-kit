# templates/company-intro — 회사소개서 마스터 v3 (발표 톤 참고용)

`VAXPORT_회사소개서_템플릿_마스터_v3.html` — 한준이 만든 회사소개서 슬라이드 마스터(2026-09-04 전달). 4.2MB, 실사 사진 81장 내장,
브라우저에서 열고 Ctrl+P로 PDF. 6개 전문 분야(영상·홍보·교육·VR-ICVFX·디지털휴먼·미디어아트) 중 하나를 고르면 9장 슬라이드를 그 분야에 맞춰 다시 그린다.

## 스킬이 여기서 가져오는 것 (P6 · 발표자료)
- **슬라이드 구조**: 회사 일반현황 → 조직·인력 → 보유 기술 → 실적(대표 3 + 목록) → 사례 → 연혁 → R&D. 제안서의 「회사 소개·수행 능력」 장과 발표자료 순서로 쓴다.
- **「PROOF — 근거 한 줄」 표기**: 주장 카드마다 아래에 `PROOF — 특허 제10-2677114호 스튜디오 실적용` 식으로 근거를 붙인다. `distinctiveness.md` 규칙 2(주장 하나에 우리만 쓸 수 있는 근거 하나)를 슬라이드로 옮긴 형태다.
- **분야별 강조 전환**: 같은 실적을 분야마다 다른 순서·다른 문장으로 보여 준다. 공고 유형에 따라 강조를 바꾸는 방식의 실례.
- **인력 카드 서식**: 성명 · 직위·경력연수 · 대표 이력 4~10줄 · 핵심 역량 태그. 데이터는 이 파일이 아니라 위키(레퍼런스 색인 §I · 인력구성 최신본)에서 가져온다.

## 가져오지 않는 것
- **색·글꼴**: 이 파일은 짙은 남색 바탕(`--navy-deep`)·시안·노랑의 발표용 다크 팔레트다. 제안서 HTML은 회사 토큰(`scripts/ui_tokens.py`, 밝은 바탕·브랜드 남색 `#082567`)을 따른다.
  둘이 공유하는 것은 브랜드 남색뿐이다. 발표 톤이 필요하면 Figma 단계에서 정한다(`figma-handoff.md`).
- **수치·이름의 정본**: 파일 안의 직원 수·인증 수·프로젝트 수·연락처는 만든 시점(2026.06 기준 표기)의 값이다. 제안서에는 재료 팩 §5(위키 정본)의 값을 쓴다. 이 파일을 갱신하려면 위키를 먼저 고친다.

## 주의
- 대외 배포용 회사소개서라 임직원 실명·대표 실적 금액이 들어 있다. 발주처 제출 범위 안의 정보다. 재무제표·원가·신용등급은 없다(`guardrails.md` §2 원칙과 같다).
- 파일이 크다(4.2MB). `install.sh`는 `skills/`만 설치하므로 직원 PC에는 복사되지 않는다. 필요할 때 저장소에서 연다.
